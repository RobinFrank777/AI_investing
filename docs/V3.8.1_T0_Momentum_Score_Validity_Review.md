# V3.8.1 T0 Momentum / Score Model Validity Review

## 1. Objective

T0 is the correctness prerequisite for threshold governance. It tests whether the active momentum contributions have a unit, scaling, or dominance defect before T1 interprets the resulting score distribution. It does not optimize returns or select a threshold.

## 2. Production Formula

The reviewed implementation is `score.calculate_rank_score_diagnostics()` under `ScoreModelVersion = technical-score-v3.8.1-r1`.

```text
ReturnMomentumContribution = 70 × Return20D + 30 × Return60D

MACDContribution =
    +20 if MACD > MACD_Signal
    +10 if MACD > 0
    +10 if Histogram > 0

MomentumScore = ReturnMomentumContribution + MACDContribution

TechnicalScore (RawScore) =
    0.40 × TrendScore
  + 0.25 × MomentumScore
  + 0.20 × VolumeScore

FinalScore =
    0.70 × TechnicalScore
  + 0.20 × RS_Score
  + 0.10 × NearHighScore
```

`RiskScore` is an inactive zero-valued diagnostic placeholder. There is no momentum clipping or normalization. The effective FinalScore multiplier of each momentum contribution is `0.25 × 0.70 = 0.175`.

## 3. Input Units

- `Return20D` and `Return60D` are decimal simple returns: `0.10` means 10%, not 10 percentage points. Thus returns of 10% and 20% contribute `7 + 6 = 13` score points.
- `MACD`, `MACD_Signal`, and `Histogram` retain the price-unit output of the EMA calculation. Their magnitudes are not inserted into the score; only boolean states are used.
- Trend, volume, MACD, RS, and NearHigh inputs become score points through discrete rules or percentile ranking.

No decimal/percentage conversion mismatch was found.

## 4. Theoretical Contribution Ranges

| Contribution | Input/form | Theoretical range | Cap/clipping | Effective FinalScore weight |
| --- | --- | --- | --- | ---: |
| ReturnMomentumContribution | `70×R20 + 30×R60`, decimal simple returns | minimum -100 when both returns are -100%; upper bound unbounded | None | 0.175 |
| MACDContribution | three boolean state bonuses | discrete `{0, 10, 30, 40}` | 0–40 | 0.175 |
| MomentumScore | sum of the above | minimum -100; upper bound unbounded | None | 0.175 |

Because `Histogram = MACD - MACD_Signal`, the +20 and +10 histogram conditions normally occur together. A score of 20 alone is therefore not a reachable ordinary state; this is consistent with the code and existing formula, not an implementation error.

The return term has a naturally wider theoretical upper tail than the capped MACD term. This is an explicit consequence of an uncapped linear return design. Theory alone is insufficient to label it defective, so empirical and sensitivity evidence follows.

## 6. Contribution Share

Shares use absolute magnitude:

```text
ReturnShare = abs(ReturnContribution) / (abs(ReturnContribution) + abs(MACDContribution))
MACDShare   = abs(MACDContribution)   / (abs(ReturnContribution) + abs(MACDContribution))
```

This avoids misleading signed division when contributions offset. Zero denominators are N/A; none occurred in the empirical sample.

| Share | Mean | P25 | Median | P75 | P90 |
| --- | ---: | ---: | ---: | ---: | ---: |
| Return | 49.50% | 17.06% | 38.79% | 100.00% | 100.00% |
| MACD | 50.50% | 0.00% | 61.21% | 82.94% | 92.87% |

- Return contribution has the larger absolute share in 41.86% of observations.
- MACD contribution has the larger absolute share in 58.14% of observations.

## 7. Dominance Warning

**Not triggered.** The proposed warning requires MACD median share above 75% and Return median share below 20%. Observed values are 61.21% and 38.79%.

MACD is more often the larger contribution, but Return retains substantial dispersion, dominates a large minority of observations, and materially affects cross-sectional ordering.

## 8. Sensitivity Results

Metrics are averages of daily cross-sectional comparisons. Production signals across all observations were 219 BUY, 1,980 WATCH, and 34,047 IGNORE.

| Scenario | Spearman rank correlation | Top-decile overlap | Top-20 overlap | BUY count change | WATCH count change | Rows changing signal |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Production | 1.0000 | 100.00% | 100.00% | 0 | 0 | 0 |
| Without MACD | 0.9880 | 91.18% | 91.06% | -147 | -1,051 | 1,345 (3.71%) |
| Without Return Momentum | 0.9949 | 86.33% | 89.94% | -219 | -1,051 | 1,465 (4.04%) |

### Without MACD

Median TechnicalScore change is -7.50 and median FinalScore change is -5.25. The maximum isolated FinalScore reduction is 7 points, exactly `40 × 0.175`. Ranking remains highly correlated, while selection changes show that MACD is consequential rather than redundant.

### Without Return Momentum

Median TechnicalScore change is -0.454 and median FinalScore change is -0.318 because the return contribution is centered near zero. Its tail and cross-sectional dispersion nevertheless matter: top-decile overlap falls more than in the no-MACD scenario, and removing it eliminates all BUY observations under the unchanged downstream rules. This reflects the model's intended requirement for positive return momentum, not a unit error.

### Contrast checks

- Return-magnitude contrast: on 2025-12-12, CRDO and PACS both had MACDContribution 10, while ReturnMomentumContribution ranged from -5.313 to 217.373. MomentumScore and final ranking clearly distinguish the return magnitudes.
- MACD-state contrast: on 2026-08-05, GS and SPOT had nearly identical ReturnMomentumContribution (difference 0.000021) and MACD contributions of 0 versus 10. The isolated formula effect is 2.5 TechnicalScore points and 1.75 FinalScore points. Other trend/cross-sectional inputs explain why their total scores need not differ by exactly that amount.

No sensitivity result shows one contribution making the other empirically inert or causing broad ranking collapse. Both removals change signals, yet more than 96% of observation-level signal states remain unchanged.

## 9. Correctness Interpretation

- **Design choice:** linear, uncapped decimal returns and discrete MACD state bonuses.
- **Calibration consideration:** Return has an unbounded upper tail and MACD has coarse 0/10/30/40 steps. These may merit future model research, but neither conflicts with the implemented unit contract.
- **Correctness defect:** none found. There is no percentage-unit mistake, duplicate weighting, erroneous clipping, or systematic contribution suppression.

Backtest return was not used to choose or validate the formula.

## 10. Decision

**VALID — NO CHANGE REQUIRED**

The contribution units are internally consistent, the empirical dominance trigger is not met, both contributions remain influential, and sensitivity preserves high ranking stability without revealing an anomalous single-factor takeover.

## 11. T1 Dependency

T1 may proceed on `technical-score-v3.8.1-r1`. Threshold governance should still disclose the uncapped Return tail and discrete MACD calibration as design context, but no score correction or revalidation gate is required first.
