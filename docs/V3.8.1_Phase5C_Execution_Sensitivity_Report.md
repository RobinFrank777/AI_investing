# AI_investing V3.8.1 Phase 5C Execution Sensitivity Report

## Methodology

Two non-optimized research scenarios use the same Phase 5B-1 entry events and
portfolio rules:

- Signal Close: existing signal-date Close execution and 20 ticker rows to exit.
- Next Trading Day Open: execution at the next ticker trading row’s Open, then
  exit at Close 20 ticker rows after actual execution.

No score or signal is recalculated. Events without a complete shifted horizon
remain unavailable. Same-ticker position conflicts can therefore differ.

## Results

| Scenario | Total return | Annualized return | Max drawdown | Sharpe | Trades | Win rate |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| Signal Close | 21.24% | 23.84% | -11.77% | 1.42 | 21 | 61.90% |
| Next Trading Day Open | 22.70% | 27.10% | -9.54% | 1.47 | 20 | 60.00% |

The delayed execution scenario did not degrade this sample, indicating that the
headline result is not solely caused by using the signal Close. It is not proof
that next-day execution is generally favorable: the scenario has one fewer
trade, uses a small concentrated sample, and lacks slippage/spread costs.
