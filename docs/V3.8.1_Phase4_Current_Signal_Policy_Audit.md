# AI_investing V3.8.1 Phase 4 Current Signal Policy Audit

Audit date: 2026-08-12

## Current Signal Policy

Source path: `rank_stocks_v2.py` → `score.calculate_final_score()` →
`trade_signal.generate_signals()`.

### BUY

All conditions must be true:

- `FinalScore >= 75`
- `Volume_Ratio > 0.8`
- `DistanceToHigh >= 0.95`
- `Close > MA20`
- `MA20 > MA60`

### WATCH

- `FinalScore >= 60`
- A row meeting every BUY condition is subsequently overwritten from WATCH to
  BUY.

Therefore, WATCH represents FinalScore at least 60 unless all BUY filters pass.
It includes scores above 75 that fail any additional BUY filter.

### HOLD

No HOLD state exists in the production ranking signal policy. The third state
is `IGNORE`, assigned by default when FinalScore is below 60.

### Additional conditions and ordering

- FinalScore is calculated as `0.70 × Score + 0.20 × RS_Score + 0.10 ×
  NearHighScore`.
- `RS_Score` is the percentile rank of 60-day return within the symbols
  processed in that run.
- Signals are assigned before rows are sorted by descending FinalScore.
- No position, portfolio, fundamental, order-review, or Investment Profile
  field participates in this technical BUY/WATCH/IGNORE classification.
- The signal is a screening classification; it does not place an order.

## Threshold inventory

| Stage | Threshold |
| --- | ---: |
| WATCH | FinalScore ≥ 60 |
| BUY score gate | FinalScore ≥ 75 |
| BUY volume gate | Volume_Ratio > 0.8 |
| BUY proximity gate | DistanceToHigh ≥ 0.95 |

The BUY score threshold and all filters remained unchanged in Phase 4.
