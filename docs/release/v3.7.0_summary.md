# AI_investing v3.7.0 Release Summary

## Overview

AI_investing v3.7.0 is the first stable release after system architecture consolidation.

This version establishes a verified Daily Research User Layer on top of the existing AI_investing research pipeline while preserving the existing research calculation architecture.

---

## Major Improvements

### 1. Daily Research User Layer

v3.7.0 introduces a unified daily research interface for reviewing research outputs.

The user layer includes:

- Research Status
- Top 10 Research Candidates
- Human Research Queue
- Data Review Queue
- Risk Watchlist
- Data Quality summary

The user layer consumes existing research artifacts and does not recalculate factor scores, rankings, signals, or risk metrics.

### 2. Daily Report

Official user entry point:

`python daily_report.py`

The command generates:

- `results/daily_investment_report.md`
- `results/daily_dashboard.html`
- `results/risk_alerts.csv`

### 3. Dashboard

The Daily Research Dashboard provides:

- Research Universe status
- Research completion status
- Validation status
- Top 10 candidates
- Human Research Queue
- Data Review Queue
- Risk Watchlist
- Artifact availability
- Data Quality information

### 4. Risk Alert Layer

The release adds a dedicated presentation layer for existing research warnings.

Current alerts include:

- Validation warnings
- Historical-data warnings
- Research-review warnings
- Data-quality warnings

The alert layer does not introduce new investment-risk thresholds.

### 5. Research and Data Review Separation

Investment-research candidates and data-quality issues are presented separately.

Human Research Queue contains existing ranked research candidates.

Data Review Queue contains detailed data-quality and validation issues requiring review.

This keeps research prioritization separate from data-maintenance work.

### 6. Duplicate Warning Cleanup

Repeated warning text in the Daily Dashboard and Daily Investment Report was removed.

Detailed issues are shown in the Data Review Queue while summary sections retain only aggregate warning counts.

---

## Architecture

The Phase 9L user layer remains separated from the research calculation layer.

The Dashboard and Daily Investment Report consume existing research artifacts.

They do not recalculate:

- Factor scores
- Rankings
- Signals
- Risk metrics
- Universe membership
- Pipeline results
- Validation logic

The existing research pipeline remains the system source of truth.
