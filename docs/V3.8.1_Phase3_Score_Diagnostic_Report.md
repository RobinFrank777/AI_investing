## 3. Momentum Analysis

### Return distributions

- 20-day returns range from -21.21% to +39.85%; P5/P95 are -16.23%/+27.93%.
- 60-day returns range from -21.23% to +88.70%; P5/P95 are -12.58%/+81.97%.
- No symbol exceeded the diagnostic extreme flags of absolute 20-day return
  above 50% or absolute 60-day return above 100%.
- ReturnMomentumContribution ranges from -17.72 to +54.51 points. Its high end
  can materially affect MomentumScore, but the observed returns do not indicate
  a single obvious data-error outlier.

### MACD versus return contribution

- MACDContribution values were 0 (2 symbols), 10 (3), 30 (7), and 40 (7).
- Mean absolute MACDContribution was 27.37 versus 11.13 for return contribution.
- Only 3 of 19 symbols had an absolute return contribution larger than the
  absolute MACD contribution.
- MomentumScore correlation was 0.7504 with MACDContribution and 0.8283 with
  ReturnMomentumContribution. Return values provide substantial differentiation
  despite their smaller average absolute size because they are continuous.

Answers:

1. **Does MACD dominate MomentumScore?** In point level, generally yes: its
   average absolute contribution is about 2.46 times the return contribution,
   and it is larger for 16/19 symbols. It does not fully dominate variation;
   continuous return contribution has the higher simple correlation with the
   resulting MomentumScore in this sample.
2. **Does return contribution provide differentiation?** Yes. Its standard
   deviation is 16.61 and range is 72.23 points, compared with four discrete
   MACD states.
3. **Are extreme returns distorting scores?** No clear data-error extreme is
   present under the stated flags, but the unbounded linear return formula
   permits high 60-day returns to produce large contributions. This merits
   future multi-date evaluation, not a Phase 3 formula change.
4. **Are score ranges reasonable?** They are arithmetically consistent with the
   current rules. MomentumScore is not bounded because returns are not capped;
   TrendScore is 0–110, MACD contribution 0–40, VolumeScore 0–20, and RiskScore
   is fixed at 50. Whether these are strategically desirable is outside this
   diagnostic phase.

## 4. RiskScore Analysis

- **Is RiskScore constant?** Yes: count 19, mean/median/min/max 50, standard
  deviation 0.
- **Is RiskScore informative?** No cross-sectionally. It contains no observed
  risk input and cannot distinguish stocks.
- **Does RiskScore change ranking?** No. Its constant 5.25-point contribution to
  FinalScore preserves every pairwise ordering. It does change absolute
  FinalScore levels and can therefore affect fixed WATCH/BUY thresholds.

Recommendation for future evaluation: explicitly decide whether RiskScore is
intended as a baseline/intercept or a security-specific risk component, and
evaluate threshold effects across multiple dates before any model change. Do
not remove it based on this single cross-section. Phase 3 leaves it unchanged.
