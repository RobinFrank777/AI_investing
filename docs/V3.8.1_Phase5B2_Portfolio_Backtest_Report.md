# AI_investing V3.8.1 Phase 5B-2 Portfolio Backtest Report

Report date: 2026-08-12

## 1. Methodology

The simulation adds a capital and position layer to the validated research
chain:

```text
Production signal
  ↓ Phase 5B-1 non-BUY→BUY transition
Entry event
  ↓ capital/slot availability
Whole-share position at signal-date Close
  ↓ daily Close mark-to-market
Fixed time exit
  ↓
Cash proceeds, trade log, and portfolio equity curve
```

`portfolio_backtest.py` consumes `results/production_trade_events.csv`. It does
not recalculate signals or scores and does not modify any production portfolio,
position-sizing, risk, order-review, or legacy-backtest module.

## 2. Simulation Rules

### Capital

- Starting capital: $100,000, matching `config.ACCOUNT_VALUE`.
- No borrowing, leverage, or short selling.
- Cash cannot become negative.

### Entry and execution

- Entry candidates are the existing Phase 5B-1 trade events.
- Entry execution price is signal-date Close (`EntryPrice`).
- No slippage or transaction costs.
- Exits are processed before new entries on the same date.
- Simultaneous candidates are processed by descending existing EntryFinalScore,
  then ticker for deterministic ties. This is scheduling under scarcity, not a
  new score or signal rule.
- A ticker cannot be opened while an earlier position in the same ticker is
  active.
- Events without a complete selected holding-period exit are excluded rather
  than assigned an invented price.

### Allocation

- Maximum concurrent positions: 10, matching `config.MAX_HOLDINGS`.
- For each accepted entry:
  `allocation = available cash / remaining position slots`.
- Shares are whole shares: `floor(allocation / EntryPrice)`.
- Unused fractional-share cash remains in cash.

This rule reserves approximately one equal slot of current cash for each
remaining capacity slot. It is a research assumption and does not call or alter
production position sizing.

### Holding and exit

- Primary holding period: 20 trading days.
- Exit: Close exactly 20 ticker trading rows after entry.
- Exit reason: `TIME_EXIT_20D` only.
- No stop loss, trailing stop, signal exit, profit target, or discretionary
  exit.
- The engine also supports an optional fixed 60-trading-day run via
  `holding_days=60`; no period was optimized.

### Equity accounting

- Open positions are marked daily at canonical Close.
- `PortfolioValue = Cash + PositionsValue` on every curve row.
- Daily returns are computed from consecutive portfolio values.
- Drawdown is portfolio value divided by its running maximum minus one.

### Optional 60D diagnostic

The unchanged engine run with `holding_days=60` produced 10 completed trades,
37.73% total return, 42.90% annualized return, -9.46% maximum drawdown, 21.85%
annualized volatility, and a 1.74 Sharpe estimate. Nine of ten trades won.

This sample is too small and concentrated to compare holding periods or infer
that 60D is superior. It is reported only because optional 60D analysis was
requested; 20D remains the primary specified simulation.

## 4. Limitations

- **Current-universe survivorship bias:** signals use today’s 19-symbol
  watchlist historically.
- **No point-in-time universe:** historical membership is unavailable.
- **No transaction costs, commissions, taxes, spreads, or slippage.**
- **Signal-date Close execution is optimistic operationally:** a score using
  that Close may not be executable at the identical closing print.
- **Fixed holding period:** production has no matching exit policy; 20D and 60D
  are research assumptions.
- **Equal-slot allocation:** it is not the production sizing model and produces
  substantial cash drag when fewer than ten slots are occupied.
- **No signal exit, stop, trailing stop, or risk-based liquidation.**
- **Same-ticker re-entry is suppressed while held:** this is necessary for
  coherent position accounting but is not a production signal change.
- **Limited historical regime:** 228 trading rows cover roughly one year.
- **Concentration:** only six tickers generated executed 20D trades; results are
  sensitive to a small number of names.
- **No benchmark or risk-free return:** Sharpe assumes zero and no excess-return
  benchmark comparison is claimed.

## 5. Integrity and Validation

Automated tests verify:

- cash plus marked position value equals portfolio value every day;
- simultaneous entries create multiple positions without exceeding capacity;
- time exits occur exactly 20 trading rows after entry; and
- equity-curve daily returns and drawdowns reconcile.

The maximum observed accounting residual was below $0.00000000003 and cash
never became negative.

## 6. Recommendation

The first portfolio simulation is complete and suitable for model review. Its
main finding is not simply the 21.24% historical return: capital remained mostly
idle and only 21 trades were executed, so results are sparse and concentrated.

Before any production inference, a future approved phase should test
point-in-time universes, next-session executable prices, costs/slippage,
benchmark comparison, and out-of-sample regimes. Those tests should diagnose
the current assumptions rather than optimize them in-sample.

The conservative interpretation is a reconciled research simulation, not proof
of future portfolio performance.
