# AI_investing V3.8.1 Phase 5C Performance Contribution Report

## Methodology

Contribution uses realized zero-cost Phase 5B-2 trade P/L. ContributionPercent
equals ticker P/L divided by total realized P/L. Negative contributors therefore
have negative percentages, and positive contributors can sum above 100%.
