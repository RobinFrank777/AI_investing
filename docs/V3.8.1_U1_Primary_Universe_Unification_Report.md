# V3.8.1 U1 Primary Universe Unification Report

## 1. Problem

The repository previously had multiple potential Universe authorities. The production market-data path defaulted through `universe_source.py` and `universe_manager.py` to `data/watchlist.csv`; ranking, validation, and backtesting also reached that file through the legacy `watchlist.py` API. Separately, Universe150 research modules used `universe_loader.py` and `data/AI_investing_universe_150_V2.csv`.

## 2. New Contract

`data/AI_investing_universe_150_V2.csv` is the sole formal Primary Investment Universe. `config.PRIMARY_UNIVERSE_PATH` and `config.PRIMARY_UNIVERSE_VERSION` define its path and identity.

The canonical loader trims and uppercases tickers, rejects empty or normalized duplicate tickers, and preserves CSV order. It neither adds nor removes members and does not inspect local market-data availability when determining membership.

## 3. Legacy Policy

`data/watchlist.csv` is retained as **LEGACY / COMPATIBILITY ONLY**. It is no longer the default authority used by the production analysis chain. The `watchlist.load_watchlist()` name remains available for caller compatibility, but now returns the canonical Primary Universe.

## 4. Production Consumers

The following production consumers now trace to `PRIMARY_UNIVERSE_PATH`:

- `update_data.py` through `universe_source.load_active_universe()`
- `rank_stocks.py` and `rank_stocks_v2.py`
- `data_validator.py`
- `backtest_engine.py` and `run_all.py`
- `score_threshold_analysis.py`
- `tools/build_fundamentals.py`
- factor snapshot and factor validation defaults through `universe_source.py`
- downstream fundamental, combined-score, candidate, and report stages through their upstream canonical inputs

## 5. Research / Compatibility Exceptions

- `universe_source.py` retains explicit `groups` mode for research/compatibility; it is not the default production authority.
- An explicitly supplied `watchlist_path` continues to use the legacy schema for compatibility and tests; it does not alter the configured Primary Universe.
- `universe_groups.py`, `factor_research_universe.py`, and `universe_scale_test.py` retain explicit research-universe behavior.
- `fetch_stock.py` is a historical standalone downloader that still reads `watchlist.csv`; the formal market-data updater is `update_data.py`.
- `system_health_check.py` retains watchlist recovery checks for the still-supported legacy artifact; this does not confer Universe authority.
- `practice/` remains historical/practice code and is outside U1 scope.

## 7. Architecture Boundary

Universe Selection ≠ Data Readiness ≠ BUY Eligibility ≠ Portfolio Eligibility.

The configured membership remains 150 even when fewer than 150 symbols have usable local market data. Data validation and ranking may report or process a ready subset, but they do not redefine the Primary Universe.
