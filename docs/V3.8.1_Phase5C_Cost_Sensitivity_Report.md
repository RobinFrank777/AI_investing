# AI_investing V3.8.1 Phase 5C Transaction Cost Sensitivity Report

## Methodology

Costs are charged on both entry gross value and exit gross proceeds. Shares are
recalculated so entry value plus cost cannot exceed allocated cash. No fixed
commission, spread model, market impact, or tax is added.

## Results

| Cost per side | Total return | Annualized return | Sharpe | Max drawdown |
| ---: | ---: | ---: | ---: | ---: |
| 0 bps | 21.24% | 23.84% | 1.42 | -11.77% |
| 10 bps | 20.34% | 22.81% | 1.38 | -11.88% |
| 25 bps | 19.64% | 22.02% | 1.34 | -11.99% |
| 50 bps | 18.11% | 20.30% | 1.25 | -12.24% |

Returns remain positive under every required scenario, but decline monotonically
as expected. At 50 bps per side, total return is 3.12 percentage points below
the zero-cost result and drawdown is modestly worse. This does not validate a
real execution-cost assumption; it only measures the specified simple costs.
