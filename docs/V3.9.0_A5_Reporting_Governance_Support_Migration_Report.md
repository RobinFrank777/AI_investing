## Selected Modules

None. No candidate satisfies every qualification gate without moving authority,
publication, CLI behavior, runtime interpretation, or an existing compatibility
surface.

`research_summary.py` is the closest support candidate, but its tests and users
patch `research_summary.build_stock_card`. A root re-export wrapper would leave
`build_research_summary` executing with canonical module globals, so that root
patch would no longer intercept the dependency. Preserving it would require a
forwarding wrapper or dependency redesign, both prohibited by the re-export-only
and move-only rules.

## Deferred High-Risk Modules

particular, report status, current/latest evidence, metadata compatibility,
NO_ACTION, FAILED precedence, health/version governance, and archive/snapshot
publication remain at their existing root authorities.

## Namespace Collision Note

Both `daily_report.py` and the `daily_report/` package remain present. Python
currently resolves `import daily_report` to
`daily_report/__init__.py`, with package search locations enabled; the sibling
file is shadowed for that import spelling. Existing tests cover the package path.
Resolving or renaming the collision is deferred to a dedicated reporting
migration because it changes public import resolution and cannot be treated as a
support-helper move.
