# V3.9.0 A2 Low-Risk Factor Primitives Migration Report

## Candidate Audit

A2 applies an all-or-nothing qualification gate at module level. A module must
be a pure computation or deterministic transformation and must have no CLI,
runtime artifact write, config dependency, metadata mutation, production
authority, or legacy backtest authority. The audit found no remaining module
that satisfies every condition.

## Selected Modules

None. Migrating zero modules is the only result consistent with the mandatory
qualification gate. A2 does not split mixed-responsibility modules because that
would be redesign rather than a move-only migration.

## Rejected/Deferred Candidates

The detailed reasons are recorded in the candidate table. In particular,
`normalize_factor_series` and `calculate_composite_row` are individually pure,
but their containing modules are not. Extracting those functions would change
module boundaries and monkeypatch surfaces, so it is deferred to an explicitly
approved decomposition phase. `indicators.py` is excluded because it is on the
production scoring path.
