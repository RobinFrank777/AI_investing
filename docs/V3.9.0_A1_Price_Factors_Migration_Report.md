# AI_investing V3.9.0 A1 Price Factors Migration Report

## Objective

Create the smallest useful `src/` package boundary by moving only the pure,
research-only native price-factor implementation. Preserve every current root
import and all behavior through a compatibility re-export. No production
investment logic or runtime path is changed.

## Before Structure

`price_factors.py` at repository root contained the only implementation. Its
three project callers were:

- `factor_engine.py`
- `factor_snapshot.py`
- `factor_validation.py`

The module had no project imports, CLI, metadata authority, file output, or
production Candidate-to-Order responsibility.

## After Structure

```text
src/
  __init__.py
  research/
    __init__.py
    technical/
      __init__.py
      price_factors.py       # canonical implementation
price_factors.py             # compatibility re-export only
```

No other `src` domain or package was created.

## Canonical Implementation Path

`src/research/technical/price_factors.py` is the sole calculation
implementation. The formulas, constants, docstrings, parameter names,
exceptions, return types, invalid/NaN filtering, stable date ordering, duplicate
date handling, and deterministic output key order were moved unchanged.

## Root Compatibility Wrapper

Root `price_factors.py` imports and re-exports the canonical public functions and
constants. It contains no function definition, calculation expression, or local
factor constant. `__all__` explicitly documents the supported compatibility
surface.

## Public API Compatibility

Functions preserved:

- `calculate_trend_value(data)`
- `calculate_momentum_value(data)`
- `calculate_volatility_20d(data)`
- `calculate_price_factors(data)`

Constants preserved:

- `TREND_OBSERVATIONS = 60`
- `MOMENTUM_OBSERVATIONS = 21`
- `VOLATILITY_OBSERVATIONS = 21`

The root and canonical functions are the same Python function objects, rather
than parallel equivalent implementations. Existing ValueError types and
messages for non-DataFrame and missing-Close inputs are unchanged.

## Import Compatibility

Both paths pass:

```python

```

Tests prove identical references, public constants, results, invalid/NaN
behavior, exceptions, and deterministic behavior.

## No Parallel Logic Proof

An AST-based compatibility test asserts the root wrapper has no FunctionDef and
no assignment other than `__all__`. Canonical implementation count: one.

## Caller Strategy

All three existing callers retain `from price_factors import
calculate_price_factors`. No caller was migrated in A1. This deliberately keeps
existing monkeypatch surfaces such as `factor_snapshot.calculate_price_factors`
and `factor_engine.calculate_price_factors` stable while proving the package
boundary underneath.
